让收款与资金归集之间 的每一步都有据可查。

一个商户，两条网络。从第一个地址到最终归集，让团队能够跟踪完整流程。
/ 01 — 工作流程

让每笔收款都可追踪。

接入一次业务系统，即可跟踪支付各阶段的状态。

  1. 01

    创建支付

    业务系统创建支付会话，获取专属收银台链接和收款地址。

  2. 02

    跟踪到账

    Reflow 监听选定网络、更新收银台状态，并向业务系统发送签名 Webhook。

  3. 03

    归集至主钱包

    通过人工操作或阈值规则，将资金从收款地址归集至主钱包。

/ 04 — 部署方式

运行在你的基础设施上。

Reflow 采用单租户部署。地址派生和交易签名在链上工作进程中运行，与 Web 应用分离。服务器、钱包配置和操作规则由你的团队管理。

支持网络TRON（TRC20）/ BSC（BEP20）USDTBSC 需在部署配置中启用。
